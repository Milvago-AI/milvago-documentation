# Getting help

| You want to… | Go to |
|---|---|
| Read the documentation | [docs.milvago.ai](https://docs.milvago.ai) (publication coming soon) |
| Ask a question, talk with other users | [Milvago AI Discord](https://discord.gg/69JPyVjqv) |
| Report an error in the documentation | [a documentation issue](https://github.com/Milvago-AI/milvago-documentation/issues/new?template=doc_issue.yml) |
| Report a bug in the product | [milvago-server issues](https://github.com/Milvago-AI/milvago-server/issues) |
| Report a vulnerability | **not** an issue — follow [SECURITY.md](SECURITY.md) |
| Enterprise edition, licensing, commercial support | [www.milvago.ai](https://www.milvago.ai) |

Community support is best effort, from maintainers and users alike. Everyone taking part is
bound by the [Code of Conduct](CODE_OF_CONDUCT.md).
